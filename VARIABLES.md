# Variable Substitution & Reusability Guide — Kavodax GTM Toolkit

This repository is built as a modular Go-To-Market framework. To repurpose this toolkit for other fintech, web3, or cross-border payment environments, swap the variables below across all Markdown and Python assets:

| Template Variable | Current Value | Functional Purpose |
| :--- | :--- | :--- |
| `[COMPANY_NAME]` | Kavodax | Target venture/client organization |
| `[PRIMARY_ASSET]` | CAGD | Native CAD stablecoin settlement rail |
| `[REGULATORY_MOAT]` | FINTRAC MSB / BoC PSP | Primary regulatory and compliance credentials |
| `[CORE_TARGET_BUYER]` | CFO / Corporate Treasurer | Primary buyer persona |
| `[PRIMARY_CORRIDORS]` | CAD-EUR, CAD-USD, CAD-BRL | Focus international trade corridors |
